# Contributing

## Reusing outside code

This website is under the BSD 3-Clause license, so any code added to it has to be compatible with those terms. Check the license before you copy or closely adapt code from another project.

| The code's license | What to do |
|---|---|
| BSD, MIT, ISC, CC0 or public domain | You can adapt it. Keep its copyright notice and license text, and say in a comment where it came from. |
| Apache-2.0 | You can adapt it, but that code stays under Apache-2.0. Do all of the above, keep any NOTICE file, and mark the files you changed. |
| GPL, LGPL, AGPL or MPL-2.0 | Don't adapt it, unless its authors give written permission to relicense it under BSD 3-Clause. |
| Non-commercial or no-derivatives terms | Don't adapt it. |
| Unknown, or no license | Don't adapt it. |

Fonts and other assets are the exception. They keep their own licenses, as long as those allow redistribution, including commercial use. Put the license file next to the asset and mention it in the README, as `site/fonts/OFL.txt` does for JetBrains Mono. An asset pasted into a page has no folder of its own, so its license goes in `site/licenses/`, as `site/licenses/octicons.txt` does for the GitHub mark.
